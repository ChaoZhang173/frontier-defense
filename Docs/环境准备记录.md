## 网页试玩

网页版本直接来自同一个 Unity 工程，首轮以电脑浏览器和键鼠为验收目标。朋友不需要安装 Unity，每个人独立游玩；本阶段不包含多人联机。

流程：Unity Web 构建 → 本机通过 HTTP 测试 → 配置 HTTPS 托管 → 检查公开链接 → 分享。

发布前检查首次加载、点击开始后的鼠标捕获和声音、Esc 暂停/退出鼠标捕获、失焦暂停、重开一局、五波胜负，以及至少 Chrome 和 Safari 的实际运行情况。构建文件的压缩、Content-Encoding 和 wasm MIME 类型必须与托管配置匹配。

浏览器支持应按最终采用的引擎版本核实，不能把 Unity 6 的手机 Web 支持直接套用于 Unity 2022。本试玩先验收电脑浏览器，手机版需另行实现操作界面并做真机性能测试。

在可运行构建产生后再选择托管方案和生成分享链接。当前没有已发布的试玩网址。
