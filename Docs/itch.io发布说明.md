### 标题

边境防线 / Frontier Defense v0.6

### 简短简介

第三人称科幻基地防守原型：带领四人小队，建设地堡与战车工厂，守住东西两路的五波攻势。

### 游戏介绍

**守住基地，抵挡五波攻势。**

《边境防线》是一款开发中的免费单人 3D 防守原型。你将扮演装甲步兵，亲自射击、调动小队、建设防线，在东西两处入口抵挡五波敌军。指挥中心被摧毁即失败；清除最后一波，赢得这场防守战。

**v0.6 可以体验：**

- **亲自守住防线：** 用磁轨步枪打击敌人，观察进攻预警，在两路之间支援。
- **指挥四人小队：** 签约两名精英雇佣兵，再免费招募两名基地守卫。让他们跟随、驻守，或进入地堡协同防守。
- **建设与升级：** 前往指挥中心强化火力、研究科技、修复建筑，建设地堡、增援兵营和战车工厂。
- **自动坦克支援：** 战车工厂建成后自动生产一辆坦克。它会驶向中央阵位、优先攻击重甲；同时最多一辆，被击毁后由工厂自动补充。
- **中央射击阵地：** 带小队到正面矮墙后展开防守，与坦克一起向基地外射击。
- **进攻敌巢炮塔：** 基地外有六座会主动攻击靠近单位的敌方防御塔。每座摧毁后获得额外 220 补给，也可以专注守住基地。

第一至第四波结束后，有 45 秒自由整备时间。你可以继续走动、招募和安排驻防；倒计时结束自动开始下一波。所有升级、建造、研究、雇佣兵签约与维修，都需走近指挥中心按 E 打开终端。终端打开时战场与倒计时暂停，返回战场后继续。

**使用电脑键盘与鼠标游玩，建议全屏。**

### 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 | WASD / Shift |
| 转动视角 | 鼠标 |
| 射击 / 精确瞄准 | 左键 / 右键 |
| 换弹 | R |
| 指挥中心：升级、建造、科技、雇佣、维修 | 靠近指挥中心正门按 E |
| 免费招募普通守卫 | 瞄准 4 米内可见的基地守卫，按 E |
| 进入地堡 | 靠近地堡后门按 E |
| 退出地堡或关闭指挥中心终端 | E |
| 小队入驻地堡 | 靠近目标地堡后门或在堡内按 B |
| 小队撤出并跟随 | F |
| 小队在此驻守 | G；靠近中央矮墙时会展开防守 |
| 暂停 / 释放鼠标 / 关闭终端 | Esc |

**初次游玩提示：**

- 先在指挥中心签下一份雇佣兵合同，再瞄准附近的普通守卫按 E，免费补充小队。
- 雇佣兵阵亡后会免费复活；招募的普通守卫阵亡后，需要重新招募。
- 战车工厂需要 650 补给、28 秒建造；完工后再用 24 秒自动生产坦克。坦克由 AI 操作。
- 波间不会自动弹出升级页。需要整备时，记得返回指挥中心。
- 玩家脱战后会自动修复，阵亡后会在基地重生；指挥中心的存亡决定胜负。

本作目前为免费原型，采用原创几何体画风，支持单人电脑键鼠操作。欢迎反馈难度、寻路、战车部署和小队指挥的体验。
