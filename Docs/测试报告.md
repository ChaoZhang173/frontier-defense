## 坦克、中央防线与集中升级

- 战车工厂 650 补给、施工 28 秒、1400 耐久；建成后用 24 秒自动生产坦克。最多同时一辆，不占小队或驻军名额。实测从工厂出口以限定速度寻路到中央阵位，逐步检查实体避障，没有传送或穿越建筑。
- 坦克 1000 耐久，优先攻击重甲，实际炮弹飞行与范围伤害均受墙体遮挡。专项验证炮管短段、炮口视线、飞行途中拦截、范围伤害与友军免伤；坦克阵亡后补产，工厂失守暂停生产，重建后继续。
- 中央墙降低且收窄，四名队员实际走到左右射击位，中央留出坦克通道。玩家真实开火与四名队员弹道均能越墙射向外侧坡道；玩家通过实际移动入口前进时仍被矮墙阻挡，不能自动跨墙走落中央悬崖。原东西线寻路、三面坡与地堡流程全部回归通过。
- 所有个人升级、建筑升级、施工、研究、雇佣和维修要求玩家在指挥中心附近按 E 打开终端。战斗与整备均可办理，普通暂停不会授予远程购买权限；终端开启时冻结战场和所有计时，关闭后继续。
- 第一至第四波结束进入 45 秒自由整备，保留小队指令，可移动、射击、招募和部署；不自动弹出升级菜单，倒计时结束开启下一波。第五波清场直接胜利。真实击杀完成一波后验证这些转换。

开发中发现并修复了矮墙遮挡下坡步枪弹道、角色自动跨越低墙，以及旧测试未切换真实终端状态的问题。早期失败报告保存在 `first-run`、`second-run`、`third-run`，顶层 JSON 为最终全部通过的运行；没有删除这些行为要求或降低判定阈值。

## 敌方防御与难度

六处敌巢各有一座防御塔：650 耐久、22 米攻击范围，每 1.25 秒发射造成 22 伤害的弹体。自动攻击接近且可见的玩家、普通守卫、小队或坦克，避开驻堡单位；真实弹道受途中遮挡。每座首次被摧毁奖励 220，本局不重生，残骸仍有实体碰撞。

35 项炮塔专项覆盖目标类型、射程边界、遮挡、途中拦截、暂停/结束/整备、一次性奖励及波次独立性。防御塔为可选目标，不占移动敌人上限、不计入波次击杀，不要求全部拆塔才能胜利。

五波为 **40 / 58 / 92 / 120 / 150，共 460**，相比 v0.5.1 增加 52。第三至第五波增强重甲和远程配置，保留双线错峰协同；同时最多 65 个进攻单位，超额排队。96 项进攻专项包含真实出兵、方向和兵种守恒、成组推进与领队替补、满额后补位、暂停与胜利。专项额外用 65 名占位敌人触发上限，因此其 525 名生成数等于 460 正常队列加 65 探针，不能当作正常一局人数。

## 四种打法对照

相同固定随机种子、相同自动射击与移动控制器，均等待完整 45 秒整备；自动玩家实际走到指挥中心才购买，没有远程购买或传送。基础打法不招募、不扩建、不研究建筑科技；小队打法带 2 名雇佣兵与 2 名守卫并强化建筑；扩建打法增加西堡、增援兵营与研究；坦克打法再建战车工厂。各打法按实际缺损阈值维修。

三条通关策略均实际生成并消灭 460 个敌人；基础打法在第四波失败时生成 310、消灭 300。配坦克的完整对局实际生产一辆、未损失，发射 86 发炮弹、取得 4 次击杀；范围伤害和协助输出不能仅用最后一击数衡量。

“防线附近”按移动敌人位置 z≤31 统计，不把固定炮塔算入；“双线同时承压”要求两侧各至少 3 名移动敌人在该区域。累计损伤是实际扣血总量，受维修影响。两种扩建打法的驻军上限均为 12，基础与小队打法为 8，守卫损失不能单独代表策略优劣。

相较 v0.5.1 的小队对照，本次玩家阵亡从 3 增至 5，守卫损失从 6 增至 13，双线承压从 18.5 秒增至 39.7 秒；基础打法从第五波失败提前到第四波。增加收入与中央阵地也改变了战斗，不能只归因于人数。完整经营仍可守住，坦克对照的地堡累计损伤由无坦克的 561 降到 0，指挥中心累计损伤由 153 降到 85。

挂机在第一波约 65.4 秒失败，预先破坏防线约 38.9 秒失败。这些是固定控制策略下的可复现对局，用于发现差异，不等于真人通关率或最终手感验收。

## 收入与主动拆塔

击杀迅行兽 / 酸脊兽 / 铁甲兽奖励提高到 **10 / 18 / 48**；五波奖励为 **175 / 210 / 245 / 280 / 315**。保留原有建筑与升级价格，新工厂一次性花费 650，坦克免费自动补产。

四条自动策略都通过真实步枪射击拆除了六座塔，额外收入 1320。步枪射程大于炮塔，自动玩家能从远处射击；这些是包含全部拆塔奖励的收入，不能视为只守波次的收益。通关总收入 10315，其中最后一波 3379；初始补给 160，最终余额均满足“160 + 收入 − 支出”。坦克经营策略前四次整备后余额为 1295 / 497 / 976 / 1586，经济较上一版宽松，符合本轮增加收益的要求。
