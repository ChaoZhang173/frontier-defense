## 新进攻机制

五波仍为 40 / 58 / 80 / 100 / 130，共408人，分为4 / 5 / 8 / 8 / 8批。每路人数均匀拆分，避免一人尾批。前两波分别进攻西侧、东侧；第三波起两路按4秒错峰，形成重叠攻势。

87项专项包括真实队列总数、兵种和方向守恒、六处敌巢、暂停冻结、方向和兵种预警、集结、慢速领队协同、领队死亡、缺员超时和完整过波条件。专门生成65名占位敌人，实际触发满额等待、释放后补位，没有漏发或重发；连同408名正常队列，专项总计473名实际出生并死亡，峰值65。

实际混编队伍集结约9.9秒后推进，锚点行进13.8米，抽查时最大队形偏离1.61米；逐步验证推进时成员不会被甩出8米协同阈值。重甲位于前排、远程兵位于后排；队伍有20秒集结和30秒推进兜底，避免缺员或拥堵导致无限等待。

重甲优先选择24米内可见的本侧建筑或中央指挥中心，仍保留视线、实际攻击距离与建筑碰撞约束。没有增加敌人总量、血量或伤害。

## 三种打法对照

同一固定随机种子与同一自动射击/移动控制器，使用真实命中、收入、费用、建造和研究时间。三条策略均等待完整45秒波间整备；均保留初始防线和个人伤害/协同火力购买，按缺损阈值维修。基础打法不招募小队、不扩建、不研究或强化建筑；小队打法招募2名雇佣兵和2名守卫并强化建筑；完整经营打法额外建西堡、增援兵营并完成穿甲弹与复合装甲。

“防线附近”按敌人位置 z≤31 统计，“双线同时承压”要求两侧各至少3名敌人在该区域。累计损伤是实际扣血总量，受维修影响，并不等于最大耐久减剩余耐久。扩建打法守卫上限12，另外两条为8，守卫损失不可单独作为策略优劣结论。

三种主动打法前两波均稳定清场，第三波起出现渗透与损伤，后两波压力增加。相比v0.5非扩建小队对照峰值17，当前小队策略峰值56；但旧对照提前跳过整备，本次完整等待整备，不能直接比较两版本总时长。

无人操作在第一波约65.4秒失败（40出生、17击杀），预先破坏防线约38.9秒失败。挂机失败证明基地需要玩家参与，不代表新手操作难度已经验收。以上每条是固定控制策略下的一次可复现运行；自动玩家不能替代真人难度与手感评估，也不能推出所有玩家的通关率。

## 经济决定

本轮保持击杀奖励7 / 13 / 36、雇佣与建造/研究价格。扩建策略前四次整备结束仅剩15 / 5 / 187 / 78补给，已经需要在扩建、雇佣、升级和研究之间取舍；最后一波新增2145补给且后面没有整备，造成终局余额较高。没有把终局余额误当作前期经济宽松而加价。免费招募守卫和雇佣兵免费复活规则保留。
