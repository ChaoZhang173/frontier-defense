# 五波基地防守试玩 · v0.2

状态：五波原型与 v0.2 小队功能已实现；下列目标与数值继续根据试玩调整。

## 体验目标

玩家以第三人称操控装甲步兵，在两个入口之间支援防线。基地自动补充友军，玩家通过亲自射击、优先击杀危险敌人，以及波次间的升级决定影响胜负。

美术采用原创风格化科幻：厚重装甲、清晰轮廓、冷色友军与暖色敌人。先用简单几何体完成碰撞和玩法，再逐步加入自制或明确授权的模型与动画。星际争霸只作为玩法与氛围参考。

## 第一张地图

- 一座高地基地，两个可通行入口，入口外有独立敌人出生区。
- 基地包含一座指挥中心、一座兵营和一座自动防御地堡。
- 第一版使用固定建筑位置；路线保持畅通，友军防守点分布在入口内侧。
- 地图提供能容纳肩后镜头的通道、建筑间距，以及玩家往返两处入口的路线。

## 玩家

- WASD 移动；鼠标控制镜头；左键射击；右键瞄准；R 换弹；Shift 冲刺。
- 一把自动步枪，有限弹匣与无限备弹，先专注换弹节奏而非物资搜集。
- 射击必须受到枪口至目标之间障碍物的遮挡，避免贴墙穿射。
- 玩家阵亡后短暂等待，在基地重生；阵亡期间暂停玩家操作，基地战斗继续。
- Esc 暂停并释放鼠标；浏览器失焦时暂停，返回后需要明确点击继续。

## 建筑和友军

| 对象 | 第一版行为 |
| --- | --- |
| 指挥中心 | 全局防守目标；被摧毁即失败 |
| 兵营 | 按周期生产士兵，达到上限后等待；损失后继续补员 |
| 士兵 | 前往分配的防守位置；自动索敌、射击；不能无限生产 |
| 地堡 | 固定位置自动攻击；入驻功能在后续版本实现 |

初始总友军人数上限可设为 8，作为调参起点。敌军也使用活动数量上限，超出时延迟生成，防止战斗对象无界增长。

## 敌人角色

| 类型 | 战术作用 |
| --- | --- |
| 迅行兽 | 快速近战，迫使玩家处理突破防线的敌人 |
| 酸脊兽 | 远程攻击，压制防守士兵 |
| 铁甲兽 | 慢速重甲，威胁建筑，提供需要集火的目标 |

敌人沿指定入口进攻，近处可攻击的防守单位和玩家形成阻截，突破后攻击基地目标。精确优先级和仇恨切换阈值需实测，避免频繁来回转向。

## 五波结构

| 波次 | 组合与目标 |
| --- | --- |
| 1 | 单入口少量迅行兽，教学移动、射击和装填 |
| 2 | 另一入口进攻，加入少量远程敌人，提示战线变化 |
| 3 | 两入口错峰进攻，引导玩家判断支援顺序 |
| 4 | 重甲单位带队，鼓励集中火力 |
| 5 | 两入口混合进攻；所有计划敌人生成并清除后胜利 |

每波包含出生队列、生成节奏、入口和波次预算。波次结束必须同时满足生成队列为空且活动敌人为零，不能因短暂清场提前获胜。

波次之间有短暂整备期，提供明确的“提前开始下一波”按钮。目标单局约 10–15 分钟，最终时长依据实测调整。

## 基础成长

击杀和完成波次提供统一资源，升级同时检查价格与等级限制。

- 玩家强化：提高步枪伤害。
- 防线强化：提高友军火力。
- 紧急维修：恢复指挥中心一定生命值。

菜单仅在波次间开放，操作时释放鼠标。升级应显示实际效果、价格和剩余资源。

## 实现顺序与验收

1. 环境：Unity Editor 能启动，URP 空工程可运行，Web 模块可用。
2. 射击样机：第三人称移动、镜头遮挡、射击命中和一个敌人；导出本地 Web 构建并实际运行。
3. 一波防守：敌人从入口进攻；指挥中心可受损；兵营补员；士兵与地堡能自动攻击；有失败与重开。
4. 五波试玩：两入口、三种敌人、资源升级、明确胜负与重开；死亡重生流程正确。
5. 分享版本：加载与操作说明、声音、质量选项；验证托管地址、浏览器控制台和完整游戏流程。

性能以真实设备测试为依据。初始目标是在开发 Mac 和约定的普通电脑浏览器中维持流畅体验；实测前不承诺特定帧率、下载体积或手机兼容性。

## v0.2：小队与射击反馈

- 开局 160 补给。靠近指挥中心正门按 E 打开小队终端，战场暂停；波间也可雇佣。每人 120，最多 3 人，独立于兵营的 8 名驻军。
- F 跟随玩家；G 在玩家当前地点驻守。队员会绕开建筑，通过基地坡道，移动中仍可射击。
- 射击可标记目标供队员集火；超过有效射程或被障碍物遮挡时，队员寻找可见敌人。
- 每人 220 生命；受伤 6 秒后每秒修复 7，波间恢复 100。阵亡需花补给重新雇佣；玩家阵亡不会清空小队。
- 小队受“协同火力”升级影响。队员名称、生命、命令和集火目标在界面显示，驻守地点有地面标记。
- 增加移动加减速、平滑瞄准、可恢复后坐力、动态准星、枪口闪光与声音，以及普通命中、弱点命中、击杀的不同反馈。
- 弱点命中乘以 1.65；重甲减伤仍生效。玩家与队员子弹可穿过友军单位，仍受建筑和墙壁遮挡。
- 以实际运行的小队专项检查、完整五波回归，以及 Mac / 本机网页画面验证作为验收依据；真人手感与难度仍需试玩反馈。
