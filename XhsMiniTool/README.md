# 边境防线 v0.6.4 小红书兼容版

入口：`dist/index.html`。下载：[FrontierDefense-0.6.4-XHS.zip](https://github.com/ChaoZhang173/frontier-defense/releases/download/snapshot-2026-11-01/FrontierDefense-0.6.4-XHS.zip)。本地打包输出仍为 `../Releases/FrontierDefense-0.6.4-XHS.zip`。

2026-11-01：源码和已有 ZIP 归档至 GitHub；此操作不代表上传或发布到小红书。v0.7 实验源码和旧包另存于 [`../Verification/xhs-v0.7/`](../Verification/xhs-v0.7/README.md)。

这是按现有 Unity v0.6 规则重写的离线 HTML / JavaScript 版本，保留五波进攻、基地建设、四人小队、雇佣兵、科技与坦克。它使用轻量几何模型；战斗弹道、敌人集结和编队为兼容版实现，不是 Unity 构建的逐帧复现。

## 操作与方向

- 开始页和暂停菜单可以选择“横屏游玩”或“竖屏游玩”，默认横屏。
- 平台固定竖屏时，游戏在容器内旋转布局。手机物理旋转后会重新计算布局，不会重复旋转。
- 摇杆移动、右侧拖动转向、独立按住射击、瞄准、换弹、交互与小队指令。
- 切换方向、调整尺寸、暂停和切后台都会清除手势，避免持续误射或转向。
- 电脑支持 WASD、拖动视角、左键射击、E 交互、R 换弹、F/G/B 小队指令。
- 单人离线，本局进度退出后重置。

## 性能回退

几何按类型合批，保留全部实体。默认画布 DPR 上限 1.4、约 200 万像素；持续低帧率会降低至 DPR 1、约 100 万像素并关闭短暂特效。低档持续不可交互、缺少图形能力或图形上下文丢失时，停止高成本循环并显示可理解的重新加载界面。没有声称真实设备已达到特定帧率。

## v0.6.1 操作修正

- 修复屏幕左右与世界坐标左右相反：摇杆平移、触屏水平转向、鼠标拖动和左右方向键统一以真实相机方向为准。使用真实 Three 相机投影覆盖多种朝向与四种屏幕布局。
- 普通方向下弹窗使用原生竖向滚动，允许从卡片和按钮上滑动。旋转方向下按画面的逻辑纵轴拖动滚动，并提供衰减惯性、边界停止、拖动后点击拦截。
- 切换方向、面板或离开应用时停止菜单惯性和拖动，保留轻点按钮与滑块操作。
- 原输入符号测试没有验证镜头投影，已补充 projection-review.cjs 防止再次出现这种遗漏。

手势规则依据：[W3C Pointer Events 的 touch-action 与旋转坐标规则](https://www.w3.org/TR/pointerevents3/#determining-supported-direct-manipulation-behavior)。新检查属于事件模拟和相机几何验证，仍须用最新二维码在目标手机确认实际手感。


## v0.6.2 横屏菜单连续触摸修正

- 修复触摸从文字、卡片或按钮开始时，仅移动最初一小段的问题。触摸目标先隐式捕获指针；转交给面板时，子元素的 `lostpointercapture` 会冒泡。现在只在面板自身丢失捕获时结束拖动。
- 横屏菜单使用一套惯性处理，达到边界即清除速度，反向滑动立即响应。竖屏继续使用原生滚动。
- 忽略宽高没有变化的 resize 通知，防止无实际布局变化时中断长拖；实际尺寸或方向变化仍清理输入。
- 增加连续多事件、子元素捕获转交、整页科技列表、边界反向拖动和真实捕获丢失的回归模拟。旧测试只模拟面板自身释放捕获，未覆盖触摸子元素的隐式捕获，电脑鼠标测试也未暴露此问题。

根因事件依据：[W3C Pointer Events 隐式指针捕获](https://www.w3.org/TR/pointerevents3/#implicit-pointer-capture)与[待处理捕获的转交顺序](https://www.w3.org/TR/pointerevents3/#process-pending-pointer-capture)。事件模拟不等同 iPhone 小红书真机测试；仍需用 v0.6.2 预览确认手感。

## v0.6.3 射击操作优化（2026-09-16）

根据 v0.6.2 试玩反馈完成两项调整：

1. **角色与准星位置**：相机移至角色右肩，角色显示在准星左侧；普通与精瞄、横竖屏使用同一侧。相机中心仍作为瞄准射线，保留原有触屏辅助瞄准和地堡视角。
2. **持续射击时调整瞄准**：按住射击键后直接拖动即可转向，手指滑出按钮仍持续射击和瞄准，松开停止射击；也支持另一根手指在右侧瞄准区转向，同时用左摇杆移动。拖动方向、灵敏度和俯仰范围与原瞄准区一致。

射击按钮禁止浏览器接管滑动手势；摇杆内部触摸点转交捕获时不再被误判为松手。切换方向、暂停或切后台会清除按住状态。

本版本仅本地打包，由用户自行上传。未更新平台预览，也未正式发布。

## v0.6.4 战场与小地图方向统一

修复 Unity 风格逻辑坐标直接交给 Three.js 导致战场东西镜像的问题。逻辑坐标继续使用 +X 向东、+Z 向北；地形、建筑、角色和特效统一放入 Z 反射的渲染节点，相机位置与方向经过同一转换，瞄准射线转回逻辑坐标后计算命中。

- 默认面向北方敌军时，西线在左、东线在右；基地建筑与小地图的东西布局一致，六个敌军出生点与东西线提示保持一致。
- 左右移动、普通转向、射击键拖动瞄准及键盘转向与小地图朝向线一致。
- 保留角色位于准星左侧、瞄准辅助、地堡视角及横竖屏菜单滚动修正。
- 小地图固定北朝上；玩家转身后战场屏幕的左/右随朝向变化，东西方位本身不变。

自动回归验证实际相机投影、实际小地图绘制指令与核心命中逻辑；不等同 iPhone 真机手感验收。此包仅本地交付，未上传或发布。
