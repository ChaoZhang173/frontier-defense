地图坐标桥接后的输入与小地图回归

新建 minimap-input-review.cjs，直接记录实际 app 的小地图 Canvas 2D fillRect、moveTo 和 lineTo。测试规则为北在上、东在右；右转时箭头顺时针，向东移动时白色玩家标记右移。规则独立于源码里的 yaw 正负号。

修改前基线读取 baseline-0.6.3 中的 app/core：48 项仅 12 项通过，36 项失败。当前桥接后的代码 48/48 通过。两份 JSON 分别记录源文件 SHA256，基线可用脚本 --baseline 选项重跑。

覆盖四种物理/逻辑画面方向；普通视角拖动和射击拖瞄；左右方向键；玩家朝北右平移、朝东前进、朝南左平移、朝西后退这四种向东动作；键盘向东与向北移动。

既有 input-review 为 28/28，fire-aim-review 为 65/65，scroll-integration-review 为 40/40。旧输入数值断言已恢复为 Unity 逻辑的正 yaw 右转。屏幕方向投影断言没有删除，其渲染坐标桥接审查由并行代理负责。

本审查只执行 Node 事件模拟及实际绘制调用记录，没有操作浏览器或上传，也不将其当作真实 Canvas 栅格图像或手机体验验收。
