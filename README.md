# 边境防线 · Frontier Defense v0.1

五波、两处入口的原创 3D 第三人称基地防守试玩。使用全球版 Unity 6000.3.24f1 / URP 17.3.0，电脑键鼠操作。

## 开始试玩

- **Mac：** 打开 [Frontier Defense.app](Builds/Mac/Frontier%20Defense.app)，点击“部署到防线”。这是已经实际运行和检查过的版本。
- **Windows：** 将 [Windows 试玩包](Releases/FrontierDefense-0.1-Windows.zip) 发给朋友，完整解压后打开 `Frontier Defense.exe`。已经成功构建，尚未在 Windows 实机运行。
- **网页：** [Web 构建包](Releases/FrontierDefense-0.1-Web.zip) 已生成并在本机浏览器实际进入战斗。当前没有可分享的线上链接，原因见下文。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 转动视角 / 射击 | 鼠标 / 左键 |
| 精确瞄准 | 右键 |
| 换弹 | R，弹匣打空也会自动换弹 |
| 冲刺 | Shift |
| 暂停 / 释放鼠标 | Esc |

守住指挥中心并消灭五波共 198 个敌人。玩家可移动射击，兵营每隔一段时间补充驻军（最多 8 名），地堡自动攻击。三类敌人分别负责近战、远程与重甲突击。每波之间可升级步枪、升级基地火力或维修指挥中心。玩家脱离伤害 5 秒后自动修复，阵亡 6 秒后重生；指挥中心被摧毁则失败。

## 已实现与边界

已实现高地基地、两条坡道、第三人称相机与碰撞、射击/命中反馈/换弹、驻军部署、地堡、五波、补给升级、战术地图、中文界面、暂停与设置、胜负及重开。模型、场景和音效为原创程序生成，属于早期玩法原型。

尚未实现自由建造、机械工厂/星港、空军、驾驶载具、小队跟随、进驻地堡、联机及手机触屏操作。先体验移动、射击和两侧支援的感觉，再决定下一轮重点。

## 验证结果

- Mac：实际启动渲染，自动战斗跑通全部五波。基本机制、胜利和失败检查通过。
- 自动玩家使用实际射线射击，五波 198 个敌人全部消灭；玩家不参与时，基地在第四波失守。
- 17 项机制检查通过，包括补员上限、友军伤害、扣费/升级上限、维修、墙体遮挡、等待未刷新敌人、暂停、重生、换弹和基地失败。
- Web：在本机的 Codex 内置浏览器中实际加载、进入第一波、自动防守、暂停及恢复。未完成 Chrome、Safari 和手机真机的独立兼容性测试。
- Windows：构建成功，但本机是 Mac，未运行 Windows 版本。构建时有 18 条与本机不支持光线追踪着色器编译有关的警告；本试玩采用前向渲染，没有使用该功能。
- 最后修正了重甲单位在坡道处停滞、酸液弹道撞地面、中文字体裁切和基地地面重叠闪烁。

完整记录：[测试报告](Docs/测试报告.md)，原始结果在 `Verification/`。

## 网页发布进度

网页游戏约 14 MB，来自同一 Unity 工程，已包含压缩解码回退，普通静态 HTTP(S) 服务即可托管。不能直接双击 `index.html` 用 file:// 运行。

Sites 中已创建一个仅所有者可访问的空站点，**尚未上传或发布游戏**。公开访问及上传到 Sites 源仓库分别被自动审批拒绝，原因是当前授权未明确覆盖“向任何持有链接的人公开”和“上传到指定外部托管服务”。没有绕过拒绝，也没有向朋友发送消息。

后续需要项目拥有者明确确认：是否允许把试玩文件上传到 Sites，并让任何持有链接的人游玩。确认后可以继续已有站点，不必重新创建或重新编译游戏。

本机网页复测：在项目目录运行 `python3 Tools/serve_web.py`，然后访问 `http://127.0.0.1:8765`；该服务只监听本机，收尾时已安排停止。

## 继续开发

完整 Unity 工程在 `UnityProject/`；场景为 `Assets/Scenes/Frontier.unity`。用全球版 Unity Hub 添加此工程，并选择已经安装的 `6000.3.24f1`，即可继续编辑。

自动构建入口在 `Assets/Editor/FrontierBuild.cs`。运行程序时可用 `--frontier-check=mechanics|victory|defeat` 和 `--frontier-output=/绝对路径/报告.json` 执行诊断；正常启动不启用诊断。

字体为 Noto Sans SC 的重命名精简衍生版本 Frontier Sans，许可见 `Assets/ThirdParty/` 及试玩包内 Licenses。程序生成模型和音效没有使用星际争霸素材。

全球版安装和中国版清理记录保存在 [环境准备记录](Docs/环境准备记录.md) 与 [安装清理记录](Docs/安装清理记录.json)。
